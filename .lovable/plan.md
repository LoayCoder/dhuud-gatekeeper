

# Fix: Hide Asset Parts from Template Editor — Show Only Real Assets

## Problem
The "Inspection Checklist Questions" section still displays previously generated asset parts (e.g., "Cylinder Body Integrity", "Discharge Mechanism") with duplicates. The button to generate them was removed, but the data remains in the database and the UI section is still visible.

The template editor should show **only the Matching Assets panel** (real assets like fire extinguishers). Checklist questions (parts) belong to the **inspection session runtime**, not the template editor.

## Changes

### 1. Hide the entire "Inspection Checklist Questions" section from template editor
Remove or collapse the checklist items list, the "Add Item" button, and the empty-state warning from the template editor view. The Matching Assets panel becomes the sole content.

**File:** `TemplateItemBuilder.tsx`
- Remove the CardHeader with "Inspection Checklist Questions" title and "Add Item" button
- Remove the items list rendering (lines 200-263)
- Keep only the Matching Assets panel as the main content
- Rename the component section header to just "Template Assets" or similar

### 2. Clean up duplicate part-based items from the database
Delete the duplicate/part-based rows from `inspection_template_items` that were generated by the old "Generate from Asset Parts" flow, so they don't pollute future session checklists either.

**Action:** Database cleanup query to remove duplicates (keep one of each if needed for session use, or remove all if parts should only be loaded at session runtime from `asset_type_parts` directly).

### 3. Keep the checklist UI available only for single-asset inspection flows
The add/edit/delete item dialog code stays in the codebase but is not rendered in the template editor. It can be reused in a future per-asset inspection workspace where checklist questions are relevant.

## Files Modified
- `TemplateItemBuilder.tsx` — Hide checklist section, show only Matching Assets
- Database migration — Clean up duplicate `inspection_template_items` rows
